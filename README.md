# AlternativeCalc

> **Reactive Variable & Terminal Formula Calculator**  
> ターミナル風の数式直接入力・実行ログ管理と、スプレッドシートのように連動するリアクティブ変数、計算の枝分かれ（ブランチ）を備えたプロフェッショナル向けWeb計算ツールである。

## 概要

一般的なスマートフォンの電卓アプリでは、括弧を含む複雑な四則演算の入力や過去の計算履歴の確認・再利用が困難である。一方で、PCのターミナル（REPL環境）による計算は履歴の追跡や数式の直接編集に優れているものの、スマートフォンからの操作には適していない。

AlternativeCalc は、これらの課題を解決するために開発された計算ツールである。Material 3 Expressive の原則に基づいた洗練されたモノトーンデザインを採用し、PC・スマートフォンの双方で極めて快適な計算体験を提供する。

## 主な機能一覧

### 1. ターミナル風の数式入力とリアルタイム計算プレビュー
- 括弧や小数が混在する長大な式（例: `1122 * (4.75 + 4570) + 2500 + 2500`）をそのままタイピングして評価可能である。
- 文法的に成立した時点で、入力欄下部にリアルタイムプレビュー（`= 5,137,869.5`）が表示される。
- `eval()` や外部ライブラリを一切使用せず、純粋な自作の再帰下降（AST）構文解析エンジンによって安全かつ高速に処理される。
- JavaScript特有の浮動小数点演算誤差（例: `0.1 + 0.2 = 0.30000000000000004`）は内部で自動補正され、高精度な十進数計算が行われる。

### 2. スプレッドシート連動型のリアクティブ変数システム
- `taxA = 1.1` のように数式として入力・実行するだけで、環境変数が即座に登録される。
- 変数同士の依存関係（例: `taxB = taxA`）を定義した場合、大元の変数 `taxA` を更新（例: `taxA = 1.08`）すると、依存する `taxB` も自動的にカスケード再計算される。
- 登録された変数は画面上部の「変数チップ」に一覧表示され、ワンタップで入力中の数式へ変数名を挿入できる。

### 3. 計算履歴からの「枝分かれ（ブランチ）」機能
- 過去の計算結果カードをタップし、「枝分かれ (新タブ作成)」を選択すると、その時点の計算ログおよび変数テーブルを引き継いだ新規タブが自動生成される。
- 条件やパラメータ（税率、単価、割引率など）を変えた複数の試算パターンを、元の計算ログを保持したまま並行してシミュレーション・比較検討できる。

### 4. マルチセッション・タブ管理
- 画面上部のタブバーから、計算セッションを自由に作成・切り替え可能である。
- 各タブごとに計算履歴・変数テーブルは完全に独立して管理される。
- タブをダブルクリックまたは長押しすることで、任意のセッション名（例: `見積A`, `税率シミュレーション`）へ変更できる。
- すべてのデータはブラウザの `localStorage` に自動永続化され、リロード後も復元される。

### 5. スマートな入力補助
- 行末で `(` を押下した場合、自動的に `()` が補完され、キャレットが括弧の間 `(|)` に自動配置される（数式途中への入力時は単一の `(` のみ挿入）。
- `√` キーを押下すると、平方根関数 `sqrt()` が括弧補完付きで挿入される。
- 直前の1文字を削除する `BS`（Backspace）キーを配置している。

### 6. PWA（Progressive Web Apps）完全対応
- オフライン動作を可能にする Service Worker（`sw.js`）およびアプリアイコン（192px / 512px）を同梱している。
- スマートフォン（iOS Safari / Android Chrome）や PC ブラウザの「ホーム画面に追加」または「アプリをインストール」により、アドレスバーのない独立したネイティブアプリとして動作する。
- 通信環境のないオフライン状態や機内モードでも即座に起動して計算可能である。

### 7. 端末設定準拠のデュアルテーマ（ライト / ダーク）
- OSのシステム配色設定（`prefers-color-scheme`）を自動検出し、ライトモード・ダークモードの最適なモノトーンパレットに自動で切り替わる。

### 8. 計算履歴の CSV ダウンロード
- ヘッダー右上のダウンロードアイコンを押下することで、開いているタブの計算履歴（日時、数式、計算結果、種別）を UTF-8 BOM 付き CSV ファイルとしてワンタップで書き出し可能である（Microsoft Excel での文字化け防止に対応）。

## 5×5 キーパッド配列

| 1列目 | 2列目 | 3列目 | 4列目 | 5列目 |
| :---: | :---: | :---: | :---: | :---: |
| **C** (クリア) | **BS** (1文字消す) | **(** | **)** | **÷** |
| **7** | **8** | **9** | **√** (平方根) | **×** |
| **4** | **5** | **6** | **xʸ** (べき乗) | **−** |
| **1** | **2** | **3** | **▲** (前の式) | **+** |
| **0** | **00** | **.** (小数) | **▼** (次の式) | **=** (実行) |

---

## キーボードショートカット (PC操作時)

- `Enter`: 計算実行および変数登録
- `▲` (Arrow Up): 過去の入力式を遡って入力欄に展開
- `▼` (Arrow Down): 履歴を進める / 現在の入力に戻る
- `Esc`: 入力欄のクリア（ポップアップ表示時はモーダルを閉じる）

## GitHub Pages への公開手順

本リポジトリはビルド不要の完全な静的アセット（Vanilla HTML / CSS / JS）のみで構成されている。

1. GitHub 上でリポジトリ `AlternativeCalc` を作成する。
2. 本ディレクトリのファイルをプッシュする：
   ```bash
   git add .
   git commit -m "Release AlternativeCalc ver 1.0"
   git remote add origin https://github.com/<GitHubユーザー名>/AlternativeCalc.git
   git push -u origin main
   ```
3. リポジトリの **Settings** > **Pages** を開く。
4. **Build and deployment** の **Source** で `Deploy from a branch` を選択し、Branch を `main` / `/(root)` に設定して **Save** を押下する。
5. 公開URL（`https://<GitHubユーザー名>.github.io/AlternativeCalc/`）にて即座に稼働する。
