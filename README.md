# AlternativeCalc

> **計算式・連動変数・枝分かれを備えた次世代Web電卓**

## 概要

一般的なスマートフォンの電卓アプリでは、括弧を含む計算の確認や、過去の計算履歴の再利用がしづらい。一方でパソコン向けの計算ツールはスマートフォンでの操作に向いていない。

AlternativeCalc は、スマートフォンでもパソコンでも直感的に長大な計算式を入力・管理できるように作られた電卓である。見やすいモノトーンデザインを採用し、日常のちょっとした計算から、税率や割引率を変えた複雑な見積もり試算まで快適に行うことができる。

## 主な機能

### 1. 式をそのまま入力＆リアルタイムプレビュー
- 括弧や小数が混ざった長い式（例: `1122 * (4.75 + 4570) + 2500`）をそのまま入力して計算できる。
- 式を入力している最中に、画面下部へリアルタイムで計算結果のプレビューが表示される。
- 小数の計算（例: `0.1 + 0.2`）で発生しやすい端数のズレは自動で補正され、正確な結果が表示される。

### 2. 計算結果を変数に保存・活用
- 過去の計算ログをタップして「変数として保存」を選ぶだけで、計算結果を好きな名前（例: `tax` や `price`）で登録できる。
- 式の入力欄に `tax = 1.1` や `total = ans` と直接入力して登録することも可能である（`ans` は直前の計算結果）。
- 画面上部の「+ 変数」ボタンからも手軽に追加できる。
- 登録した変数は上部に並び、タップするだけで入力中の式に呼び出せる。

### 3. 変数の連動更新
- 変数の値に別の変数を含めることができる（例: `taxB = taxA`）。
- 大元の `taxA` の数値を変更すると、連動している `taxB` の値も自動的に再計算される。

### 4. 計算の「枝分かれ」機能
- 過去の計算ログをタップして「枝分かれ (新タブ作成)」を選ぶと、その時点の計算履歴と変数を引き継いだ新しいタブが作成される。
- 元の計算を残したまま、「別の割引率や税率ならどうなるか」といった比較試算を並行してシミュレーションできる。

### 5. マルチタブ管理と自動保存
- 画面上部の `+` ボタンから新しい計算タブを追加できる。
- 各タブごとに計算履歴や変数は独立して管理される。
- タブ名をダブルクリック（スマホは長押し）することで、自由に名前を変更できる（例: `見積もりA`, `別パターン試算`）。
- 入力したデータはブラウザに自動保存されるため、画面を閉じたり再読み込みしても消えない。

### 6. キーパッド表示切替・入力サポート
- ヘッダーの電卓アイコンを押すことでキーパッドを折りたたみ、画面いっぱいに計算履歴を広げて確認できる。
- キーボードアイコンを押せば、スマホ標準のキーボードを使って文字や数値を直接入力できる。
- 式の末尾で `(` を押すと自動で `()` が入力され、カーソルが括弧の間に移動する。
- 直前の1文字を消す `BS`（Backspace）キーを備えている。

### 7. CSVダウンロード
- ヘッダーのダウンロードアイコンを押すことで、開いているタブの計算履歴（日時、数式、計算結果、種別）を CSV 形式でダウンロードできる（Microsoft Excel でそのまま文字化けせず開ける UTF-8 BOM 付き）。

### 8. アプリ化（PWA）＆ オフライン対応
- スマートフォン（iOS / Android）やパソコンのブラウザから「ホーム画面に追加」または「アプリをインストール」することで、専用アプリとしてインストールできる。
- 通信環境のないオフライン状態や機内モードでもそのまま計算できる。

### 9. 端末に合わせたライト／ダークテーマ
- スマートフォンやPCの配色設定（ライトモード / ダークモード）を自動判別し、目に優しいモノトーン配色に自動で切り替わる。

## 5×5 キーパッド配列

| 1列目 | 2列目 | 3列目 | 4列目 | 5列目 |
| :---: | :---: | :---: | :---: | :---: |
| **C** (クリア) | **BS** (1文字消す) | **(** | **)** | **÷** |
| **7** | **8** | **9** | **√** (ルート) | **×** |
| **4** | **5** | **6** | **xʸ** (べき乗) | **−** |
| **1** | **2** | **3** | **▲** (前の式) | **+** |
| **0** | **00** | **.** (小数) | **▼** (次の式) | **=** (実行) |

---

## キーボードショートカット (PC操作時)

- `Enter`: 計算実行および変数の登録
- `▲` (Arrow Up): 過去に入力した式をさかのぼる
- `▼` (Arrow Down): 履歴を進める / 現在の入力に戻る
- `Esc`: 入力欄のクリア（ポップアップ表示時は閉じる）
