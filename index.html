AlternativeCalc の使い方

■ 基本的な計算

  • 四則演算（+, −, ×, ÷）、括弧 ()、小数点 .、べき乗 xʸ、平方根 √ に完全対応している。
  • 例: 1122 * (4.75 + 4570) + 2500 + 2500
  • 数式を入力している途中で、文法が成立した時点で入力欄下部に薄くリアルタイムプレビューが表示される。
  • キーパッドの = または物理キーボードの Enter を押すことで計算が確定し、上部に計算ログとして蓄積される。
  • JavaScript特有の浮動小数点丸め誤差（例: 0.1 + 0.2 = 0.30000000000000004）は内部で自動補正され、正確な十進数で評価される。

■ リアクティブ変数システム

  • taxA = 1.1 のように代入式を入力して実行することで、環境変数が登録される。
  • 登録された変数は画面上部の「変数チップ」に一覧表示され、ワンタップで数式中に変数名を挿入できる。
  • 変数同士を連動参照させた場合（例: taxB = taxA）、大元の taxA の値を更新すると、依存する taxB も自動的にカスケード再計算される。
  • 不要になった変数は、チップ右端の [×] を押すことで即座に削除できる。
  • 上部の [+ 変数] ボタンからダイアログ形式で変数を登録することも可能である。

■ 枝分かれ（ブランチ）機能

  • 過去の計算ログカードをタップするとアクションメニューが開く。
  • 「枝分かれ (新タブ作成)」を選択すると、その時点の計算履歴および変数状態をそのまま引き継いだ新しいタブ（例: Calc 1 (枝1)）が自動生成される。
  • 異なる税率、数量、割引率などを用いた別パターンのシミュレーションを、元の計算を壊さず並行して比較検討する用途に最適である。

■ タブ（セッション）管理

  • 上部タブバーの + ボタンを押すことで、独立した計算タブを自由に追加できる。
  • 各タブごとに計算履歴、変数テーブルは完全に独立して管理される。
  • タブをダブルクリック（または長押し）することで、任意のわかりやすい名前に変更できる。
  • タブの計算履歴や変数は、ブラウザの LocalStorage に自動的に保存・永続化される。

■ スマートな括弧・平方根の自動補完

  • 行末で ( を入力した場合は自動で () が補完され、カーソルが自動的にかっこの間 (|) に移動する。
  • 数式の途中で ( を入力した場合は、既存の文字を乱さないよう単一の ( のみ挿入される。
  • √ を押すと sqrt() が入力され、同様に括弧内にカーソルが自動配置される。

■ CSV書き出し ＆ PWA（アプリ化）対応

  • ヘッダーのダウンロードアイコンを押すと、現在開いているタブの計算履歴（日時、式、結果、種別）を CSV 形式でダウンロードできる（Excel対応 UTF-8 BOM付き）。
  • ブラウザメニューから「ホーム画面に追加」または「アプリをインストール」を選択することで、アドレスバーのない独立したネイティブアプリとしてインストール可能である。
  • Service Worker によりオフラインキャッシュが有効化されており、通信環境のないオフライン状態でも完全に動作する。

■ キーボードショートカット (PC)

  • Enter: 計算実行 / 変数登録
  • ▲ / ▼ (Arrow Up / Down): 過去の入力式を遡る / 次の式に進む
  • Esc: 入力欄クリア（ポップアップ表示中は閉じる）
